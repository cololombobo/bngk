# Bangkok Rail

Откройте `dist/index.html` в браузере. В папке `dist` находятся всё приложение и уличная подложка. Сборка, пакеты и ключи API не нужны.

Чтобы использовать геолокацию на iPhone, откройте страницу в Safari по HTTPS и разрешите доступ к местоположению. Кнопка геолокации показывает позицию на карте и предлагает ближайшую станцию по расстоянию по прямой. Время маршрута рассчитано приблизительно с учётом ожидания поездов и пеших переходов.

## Маршрутизация

`data.js` содержит станции, линии, геометрию и пересадки. `routing.js` работает отдельно от карты и формы. Метод `BangkokRail.findRoute(from, to, { criterion })` принимает коды станций и возвращает упорядоченные участки поездки, остановки и стоимость. Доступны критерии `fastest` и `fewest-transfers`.

Для следующего этапа места можно хранить отдельно как точки с координатами. `BangkokRail.nearestStation(point)` привязывает точку к сети, а `findRoute` даёт стоимость поездки между станциями для подбора порядка посещения. При подборе предстоит учитывать расстояние от места до станции.

Данные транспорта адаптированы из [OTP Namtang](https://namtang-api.otp.go.th/opendata) (CC BY, версия от 15 ноября 2026). Уличные данные получены из OpenFreeMap и OpenMapTiles на основе [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL).
