# Bangkok Rail

Откройте `dist/index.html` в браузере. В папке `dist` находятся всё приложение и уличная подложка. Сборка, пакеты и ключи API не нужны.

Офлайн-копия находится в `dist/bangkok-rail-offline.html`. Она открывается отдельно от папки `dist`. На сайте ссылка на скачивание есть в разделе «О карте». Чтобы обновить файл после изменения карты, выполните `node build-offline.mjs`.

На iPhone откройте сайт в Safari с интернетом и нажмите «О карте» → «Сохранить офлайн». Когда карта сохранится, ту же страницу можно открывать без сети, например из закладок Safari. После очистки данных сайта карту нужно сохранить снова.

Чтобы использовать геолокацию на iPhone, откройте страницу в Safari по HTTPS и разрешите доступ к местоположению. Началом поездки может быть сама геопозиция или ближайшая станция.

## Места по пути

Выберите начало и конец поездки, затем откройте «Места по пути». Отметьте интересы и выберите допустимое дополнительное время. Лимит включает дорогу и время на посещение. Кнопка «Заехать по пути» в карточке добавляет обязательную остановку. Маршрут сохраняет закреплённые места и показывает предупреждение, если они превышают лимит.

Через «Мои отметки» в карточке места можно сохранить оценку, цвет метки и заметку. Они хранятся в локальном хранилище браузера. Оценка повышает приоритет места при подборе, а отредактированные места появляются в «Моих местах».

## Маршрутизация

`routing.js` рассчитывает поездки по железнодорожной сети. `outing.js` сравнивает варианты с фиксированными началом и концом, отдаёт приоритет охвату выбранных категорий и учитывает оценки. Для вариантов используются оценочные времена поездки, пеших участков и посещений. Пунктир показывает приблизительные пешие участки, а ссылки в деталях открывают навигацию по улицам.

`places-data.js` хранит места, личную подборку и сроки известных временных событий. При импорте Hidden Gems in Bangkok оставлены слои баров, достопримечательностей и покупок. Точки за пределами покрытия доступны в каталоге со ссылкой на Google Maps.
